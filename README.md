## Project Overview

This project investigates how meditation reorganizes large-scale brain networks using Multivariate Autoregressive (MVAR) modeling and Granger Causality (GC).

We focus on:

- Changes in top-down information flow in the gamma band  
- Identification of directed causal networks during meditation  
- Analysis of cross-frequency causal coupling  

The goal is to understand how directed connectivity patterns differ between meditation and non-meditation states.

## Dataset

The analysis is based on EEG recordings from Brahma Kumaris (BK1) meditation practitioners.

## Repository Contents

This folder contains:

- EEG preprocessing scripts  
- MVAR modeling implementations  
- Granger Causality analysis code  
- Directed connectivity and network analysis workflows
