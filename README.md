Causal Analysis of Meditation EEG – BK1 Dataset
Group Members - Samyak, Susmit
We aim to investigate how meditation reorganizes brain networks using Multivariate Autoregressive (MVAR) modeling and Granger Causality (GC).We are intrested in examining changes in top-down information flow in the gamma band,  find causal networks during meditation, and/or analyze cross-frequency causal coupling. 
This folder contains our group’s work on directed connectivity and causal network analysis of EEG data from Brahma Kumaris (BK1) meditation practitioners. This will include preprocessing, MVAR modeling and GC analysis codes.
